## 申请 GitHub 学生包

> [!TIP]
>
> 如已获取可跳转至 [申请 Azure 服务器](#申请-azure-服务器)。

**需要准备的材料：**

- edu 邮箱（.edu.cn 也可）
- 以下证明材料==之一==（可展开查看获取教程）：

:::collapse

- 带学校英文名的校园卡

  顾名思义，没有获取教程。

  如果校园卡上没有英文名也可以尝试拍照后处理为翻译件。

- 学信网上下载的英文学籍报告

  首先你需要确认是否已经在学信网上更新学籍（大一学生可能要开学几个月后才会更新）。

  如果还没有更新就只能使用其他两个材料了。

  登录[学信网](https://my.chsi.com.cn/archive/index.action)，点击上方的==在线验证报告-高等学籍==：

  ![](https://image.honahec.cc/Screenshot%202026-07-18%20at%2022.17.32.png)

  由于我已经申请了，不确定未申请的样子，总之按照指示申请即可。

  如果能申请英文报告可直接申请，若不能也可以申请中文后翻译为英文版。

  ![](https://image.honahec.cc/20260718222230381.png)

### 正式开始申请

> [!WARNING]
>
> 请注意：建议使用==手机==（因为需要拍照），在==连接校园网、关闭代理==的环境下进行，即使在关闭代理的情况下连接不通畅也不要开启代理（因为认证需要网络定位）。

::: steps

1. 手机上打开[GitHub 学生包](https://education.github.com/pack)

   <img src="https://image.honahec.cc/Screen%20Shot%202026-07-18%20at%2022.30.34.png" width="300">

2. 点击 `Sign Up For Student Developer Pack` 后登录 Github 帐号按照系统指引进行即可。

   > [!NOTE]
   >
   > 大陆学校申请很难一次通过，个人申请三次后通过。
   >
   > ![](https://image.honahec.cc/Screenshot%202026-07-19%20at%2019.47.49.png)
   >
   > 每次申请后大约半小时可以得到 AI 审核结果（主要会对材料识图提取信息），然后进入所谓的 72h 人工审核（但实际上根本无人在意，到这一步一定会过）。

:::

## 申请 Azure 服务器

::: steps

1. 进入 [azure 学生页面](https://azure.microsoft.com/en-us/free/students)

   ![](https://image.honahec.cc/Screenshot%202026-07-21%20at%2016.27.33.png)

2. 点击 Start free 后选择使用 GitHub 登录

3. 按照指引完成学术认证，认证方式选择 GitHub

4. 正常填写信息即可

5. 参考[知乎文章](https://zhuanlan.zhihu.com/p/629609870)创建一个 Linux 服务器

:::
